HND Level 5 · Computing Research Project

Secure public Wi-Fi gateway

Free Wi-Fi in malls and metro stations is a common way to steal logins. I surveyed users, interviewed an industry professional, then built a working captive-portal prototype that makes public Wi-Fi safer.

  • Safety notice and agreement before access
  • Session tokens and time-limited access
  • Rules from a policy file: allow, warn or block
  • Blocks banking and payment sites, ends the session after three strikes

Final-year project · LJMU via Westford · in progress

Fake Wi-Fi (evil twin) detector

My final-year project picks up where the gateway left off. It uses machine learning on low-cost ESP32 hardware to spot short-lived "evil twin" hotspots: fake networks that copy a real Wi-Fi name to steal logins. The goal is detecting them in real time, before people connect.

Machine learningESP32Wireless security
